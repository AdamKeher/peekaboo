# Ordered list of everything scripts/build_puae.ps1 and scripts/build_puae.sh do to
# external/libretro-uae between extracting it and running make. Both scripts read this
# file, so a change here reaches every platform at once.
#
# An entry is either:
#   <path>    a patch file, relative to patches/, applied with `git apply` in this order
#   @<phase>  a named step implemented in both build scripts (a file copy, an append or
#             a substitution - things a patch cannot express)
# Blank lines and lines starting with '#' are ignored.
#
# Patches are applied against libretro-uae 2b0ed42 with exact context, so ORDER MATTERS:
# a patch's context includes every earlier patch's output. Add new work at the end
# unless it has to interleave. The numeric prefixes leave gaps for that.
