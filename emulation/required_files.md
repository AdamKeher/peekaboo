## Optional ROMs (CD32, CDTV, SCSI cards):

Not shipped. Put them in this directory, or point Emulator > Preferences > Kickstart ROM at a folder that holds them. The core also accepts the Amiga Forever names in brackets.

| Length | Name | Needed for |
| --- | --- | --- |
| 524288 | kick40060.CD32 (amiga-os-310-cd32.rom) | CD32, CD32FR |
| 524288 | kick40060.CD32.ext (amiga-os-310-cd32-ext.rom) | CD32, CD32FR |
| 262144 | kick34005.CDTV (amiga-os-130-cdtv-ext.rom) | CDTV |
| 16384 | any name, set with HD ROM or the Hard Drives window (amiga-boot-a590.rom) | A590/A2091 SCSI |
| 32768 | any name, set the same way (amiga-boot-a4091.rom) | A4091 SCSI |
